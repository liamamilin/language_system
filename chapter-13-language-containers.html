15  第 13 章：Language 的 Container 示例（Language Containers）

15.1 本章要解决的问题

第 12 章梳理了 Language 语言单位下的 8 个 Group。本章继续向下一层推进，展示每个 Group 下可以放置哪些 Container。

语言 Container 不同于身体和心智 Container。它的主体增益更多体现在表达能力上——你能否用精确的语言命名、提问、论证和指令。

15.2 Word & Phrase 词与短语：Container 示例

15.2.1 Term 术语

Term 是精确命名一个概念的词。一个好的术语用一个词替代一段解释。

收纳 RU：RU、Theme、Container、Subject Gain Principle

主体增益：术语提升表达密度。“RU”两个字替代了”可以被当作一个东西来指称和安置的语义单位”这一整句。掌握一个域的关键术语是进入该域的快捷方式。

常见用法：

常见搭配： - define a term 定义一个术语 - use a technical term 使用一个专业术语 - borrow a term 借用一个术语

常用句型： - This term captures a concept I have been trying to name. 这个术语捕捉了我一直想命名的概念。 - Using the right term reduces the need for long explanations. 使用正确的术语减少了长篇解释的必要。

概念安置卡：

RU 名称：Term

主位置：Language → Word & Phrase → Term

关联位置：
- Language → Concept → Core Concept

关联动作：define, adopt, share, clarify

关联属性：precise, vague, accepted, disputed

说明：Term 是精确命名单位。它帮助主体用最小语言单位传递精确概念。

15.2.2 Label 标签

Label 是对事物进行分类或标记的简短词。它不像 Term 那样有精确定义，但能快速建立分类。

收纳 RU：tag、category、status、priority label

主体增益：它帮助主体快速组织和检索信息。标签不是精确术语，但它是信息管理的轻量工具。好的标签系统让信息更容易被找到。

常见用法：

常见搭配： - add a label 添加标签 - remove a label 移除标签 - the label is misleading 标签有误导性

常用句型： - I use labels to organize my notes. 我用标签来组织我的笔记。 - A label is not a definition, but it helps with retrieval. 标签不是定义，但它帮助检索。

概念安置卡：

RU 名称：Label

主位置：Language → Word & Phrase → Label

关联位置：
- Technology → Data → Dataset
- Work → Task → Single Action Task

关联动作：add, remove, organize, filter

关联属性：clear, ambiguous, useful, redundant

说明：Label 是分类标记单位。它帮助主体快速组织和检索信息，而非精确定义。

15.3 Sentence 句子：Container 示例

15.3.1 Statement 判断句

Statement 是对事物做出判断的句子。它是思考的基本输出单位——你通过 Statement 表达对某事的立场。

收纳 RU：assertion、observation、conclusion、hypothesis

主体增益：好的 Statement 能把模糊感受转化为可检验的判断。“这个方案成本太高”是一个可检验的 Statement，“我感觉不太好”则不是。培养 Statement 能力是提升思考精度的基础。

常见用法：

常见搭配： - make a statement 做出一个判断 - support a statement 支持一个论断 - challenge a statement 质疑一个论断

常用句型： - This statement needs evidence. 这个判断需要证据支持。 - Can you turn that feeling into a clear statement? 你能把那感受转化为一个清晰的判断吗？

概念安置卡：

RU 名称：Statement

主位置：Language → Sentence → Statement

关联位置：
- Language → Argument → Claim

关联动作：make, verify, challenge, qualify

关联属性：true, false, unverified, partial

说明：Statement 是判断句单位。它帮助主体将模糊感受转化为可检验的表达。

15.3.2 Action Sentence 动作句

Action Sentence 是描述具体行动的句子。它不是抽象建议，而是可执行的行动描述。

收纳 RU：instruction、command、request、call to action

主体增益：它帮助主体把”应该做点什么”转化为”具体做什么”。好的 Action Sentence 包含主语、动词和明确对象，没有模糊空间。

常见用法：

常见搭配： - write an action sentence 写动作句 - the action sentence is clear 动作句清晰 - turn a goal into an action sentence 将目标转化为动作句

常用句型： - The action sentence should be: “Write 500 words before noon.” 动作句应该是：“中午前写 500 字。” - Vague goals become clear when turned into action sentences. 模糊的目标在转化为动作句后变得清晰。

概念安置卡：

RU 名称：Action Sentence

主位置：Language → Sentence → Action Sentence

关联位置：
- Work → Plan → Step
- Work → Task → Single Action Task

关联动作：write, execute, delegate, track

关联属性：clear, vague, actionable, abstract

说明：Action Sentence 是行动描述单位。它帮助主体将模糊目标转化为可执行的具体行动。

15.4 Question 问题：Container 示例

15.4.1 Diagnostic Question 诊断问题

Diagnostic Question 用于识别当前状态或问题原因。它是理解问题的第一步工具。

收纳 RU：what question、why question、where question、how question

主体增益：诊断问题帮助主体从”这个问题好麻烦”转向”这个问题具体是什么”。好的诊断问题直接指向解决方案路径。

常见用法：

常见搭配： - ask a diagnostic question 提出诊断问题 - refine the question 改进问题 - the question is too vague 问题太模糊

常用句型： - The diagnostic question should be: what changed? 诊断问题应该是：什么变了？ - A good diagnostic question narrows down the possible causes. 一个好的诊断问题能缩小可能的成因范围。

概念安置卡：

RU 名称：Diagnostic Question

主位置：Language → Question → Diagnostic Question

关联位置：
- Work → Problem → Root Problem

关联动作：ask, refine, sequence, answer

关联属性：open, closed, narrow, broad

说明：Diagnostic Question 是问题识别单位。它帮助主体从模糊困扰转向精确排查。

15.4.2 Exploratory Question 探索性问题

Exploratory Question 是在未知领域寻找方向和模式的开放问题。它不是寻找已知答案，而是打开新的可能性。

收纳 RU：what if question、open-ended question、possibility question、discovery question

主体增益：它帮助主体区分”我在排查已知问题”和”我在探索未知领域”。探索性问题不预设答案，而是创造思考空间。在创意、研究和战略规划中，探索性问题比诊断问题更重要。

常见用法：

常见搭配： - ask an exploratory question 提出探索性问题 - the question opens new possibilities 问题打开新的可能性 - exploratory questions have no single answer 探索性问题没有单一答案

常用句型： - Exploratory questions help me discover what I do not know. 探索性问题帮助我发现我不知道的东西。 - The best exploratory questions cannot be answered with yes or no. 最好的探索性问题不能用是或否来回答。

概念安置卡：

RU 名称：Exploratory Question

主位置：Language → Question → Exploratory Question

关联位置：
- Mind → Cognition → Mental Model
- Work → Method → First Principles

关联动作：ask, explore, follow, broaden

关联属性：open, closed, generative, limiting

说明：Exploratory Question 是开放探索单位。它帮助主体在未知领域打开新的思考方向。

15.4.3 Clarifying Question 澄清问题

Clarifying Question 是用于消除模糊、确认理解的提问。它不是挑战，而是确保双方对同一件事有相同理解。

收纳 RU：confirmation question、paraphrase check、specificity question、definition check

主体增益：它帮助主体区分”我以为我听懂了”和”我真的听懂了”。大多数沟通问题源于双方以为说清楚了但实际理解不同。澄清问题是沟通中最被低估的工具。

常见用法：

常见搭配： - ask a clarifying question 提出澄清问题 - the question removes ambiguity 问题消除模糊 - clarify before responding 在回应前先澄清

常用句型： - Let me ask a clarifying question to make sure I understand. 让我问一个澄清问题来确保我理解了。 - A good clarifying question prevents costly misunderstandings. 一个好的澄清问题防止代价高昂的误解。

概念安置卡：

RU 名称：Clarifying Question

主位置：Language → Question → Clarifying Question

关联位置：
- Relationship → Conflict → Misunderstanding
- Work → Problem → Problem Statement

关联动作：ask, confirm, paraphrase, check

关联属性：specific, general, neutral, leading

说明：Clarifying Question 是沟通确认单位。它帮助主体消除模糊、确保双方理解一致。

15.5 Argument 论证：Container 示例

15.5.1 Claim 主张

Claim 是 Argument 的核心——你想证明的观点。没有 Claim 的 Argument 只是信息堆砌。

收纳 RU：main claim、sub-claim、implicit claim、rebuttal

主体增益：Claim 帮助主体区分”事实”和”主张”。人经常把自己的主张当作事实来表达。意识到”这是一个 claim，不是事实”，是理性沟通的第一步。

常见用法：

常见搭配： - make a claim 提出主张 - support a claim 支持主张 - challenge a claim 质疑主张

常用句型： - What is the main claim of this argument? 这个论证的主要主张是什么？ - This claim needs stronger evidence. 这个主张需要更有力的证据。

概念安置卡：

RU 名称：Claim

主位置：Language → Argument → Claim

关联位置：
- Language → Sentence → Statement

关联动作：state, support, defend, withdraw

关联属性：strong, weak, controversial, accepted

说明：Claim 是论证核心单位。它帮助主体区分事实和主张，提升沟通精度。

15.5.2 Evidence 证据

Evidence 是支持或反驳主张的信息。它不是观点本身，而是用来检验观点的材料——数据、案例、引用、观察结果。

收纳 RU：data point、case study、source reference、empirical finding、anecdote

主体增益：它帮助主体区分”我认为”和”我有证据表明”。没有证据的论证只是个人意见。好习惯是：每提出一个主张，自问”支持这个主张的证据是什么”。

常见用法：

常见搭配： - present evidence 提供证据 - the evidence supports the claim 证据支持主张 - evidence is insufficient 证据不足

常用句型： - Where is the evidence for this claim? 这个主张的证据在哪里？ - Strong arguments are backed by evidence, not just conviction. 有力的论证由证据支持，而非仅靠信念。

概念安置卡：

RU 名称：Evidence

主位置：Language → Argument → Evidence

关联位置：
- Work → Feedback → Error Feedback
- Mind → Cognition → Mental Model

关联动作：gather, present, evaluate, challenge

关联属性：strong, weak, direct, circumstantial

说明：Evidence 是论证支持信息单位。它帮助主体用材料而非观点支持主张。

15.5.3 Counterargument 反论

Counterargument 是对主张提出的反面论证。它不是攻击，而是检验主张可靠性的必要工具。

收纳 RU：rebuttal、opposing view、alternative explanation、objection

主体增益：它帮助主体区分”这个主张看起来很合理”和”这个主张经得起反驳”。主动寻找和考虑反论是理性思考的标志。一个能经得起最强反论的主张才是可靠的主张。

常见用法：

常见搭配： - anticipate counterarguments 预判反论 - address a counterargument 回应反论 - the counterargument is strong 反论有力

常用句型： - The best way to test an argument is to find the strongest counterargument. 检验论证的最好方法是找到最强的反论。 - If you cannot think of a counterargument, you may not understand your own argument. 如果你想不出反论，你可能没有真正理解自己的论证。

概念安置卡：

RU 名称：Counterargument

主位置：Language → Argument → Counterargument

关联位置：
- Mind → Cognition → Cognitive Bias
- Work → Method → First Principles

关联动作：anticipate, address, refute, incorporate

关联属性：strong, weak, relevant, irrelevant

说明：Counterargument 是反面论证单位。它帮助主体通过检验反驳来增强主张的可靠性。

15.6 Instruction 指令：Container 示例

15.6.1 Prompt 提示词

Prompt 是向 AI 或他人发出的执行指令。在大模型时代，Prompt 质量直接决定了输出质量。

收纳 RU：system prompt、user prompt、prompt template、prompt chain

主体增益：Prompt 帮助主体将模糊需求转化为可执行的精确指令。好的 Prompt 包含上下文、约束和期望输出格式。

常见用法：

常见搭配： - write a prompt 写提示词 - refine a prompt 优化提示词 - the prompt is too vague 提示词太模糊

常用句型： - This prompt needs clearer constraints. 这个提示词需要更明确的约束条件。 - A good prompt includes context, constraints, and expected output format. 一个好的提示词包含上下文、约束和期望输出格式。

概念安置卡：

RU 名称：Prompt

主位置：Language → Instruction → Prompt

关联位置：
- Technology → AI Model → Language Model
- Technology → Workflow → AI Workflow

关联动作：write, refine, test, optimize

关联属性：vague, precise, short, detailed

说明：Prompt 是指令执行单位。它帮助主体将需求转化为 AI 或他人可精确执行的指令。

15.6.2 Command 命令

Command 是要求对方立即执行某事的直接指令。它不是开放的请求，而是明确的、期待立刻执行的指示。

收纳 RU：order、directive、imperative、execution command、urgent instruction

主体增益：它帮助主体区分”我请求你”和”我命令你”。在紧急情况、危机管理和明确分工的场景中，直接命令比礼貌请求更有效。知道何时使用 Command 是领导力和应急能力的一部分。

常见用法：

常见搭配： - issue a command 发出命令 - execute the command 执行命令 - the command is clear 命令清晰

常用句型： - In an emergency, clear commands are more effective than polite requests. 在紧急情况下，清晰的命令比礼貌的请求更有效。 - A good command leaves no room for interpretation. 好的命令不留解释空间。

概念安置卡：

RU 名称：Command

主位置：Language → Instruction → Command

关联位置：
- Work → Task → Single Action Task
- Relationship → Cooperation → Coordination

关联动作：issue, execute, obey, question

关联属性：clear, vague, urgent, routine

说明：Command 是直接指令单位。它帮助主体在需要立即行动时发出清晰明确的执行要求。

15.6.3 Instruction Template 指令模板

Instruction Template 是预先设计好的指令格式。它不是一次性指令，而是可复用的指令模式——降低每次发指令的思考成本，提高指令质量。

收纳 RU：instruction format、prompt pattern、standard instruction、reusable directive

主体增益：它帮助主体区分”我每次重新写指令”和”我复用经过验证的指令模式”。指令模板确保每次发指令时都不遗漏关键信息——上下文、目标、约束、输出格式。

常见用法：

常见搭配： - create an instruction template 创建指令模板 - use a template 使用模板 - customize the template 定制模板

常用句型： - An instruction template ensures you never miss key requirements. 指令模板确保你从不遗漏关键要求。 - Good instruction templates are specific enough to be useful and flexible enough to be reusable. 好的指令模板足够具体有用，也足够灵活可复用。

概念安置卡：

RU 名称：Instruction Template

主位置：Language → Instruction → Instruction Template

关联位置：
- Work → Method → Template
- Technology → AI Model → Language Model

关联动作：create, use, refine, share

关联属性：detailed, minimal, specific, general

说明：Instruction Template 是指令复用单位。它帮助主体用经过验证的指令模式确保输出质量。

15.7 Text 文本：Container 示例

15.7.1 Article 文章

Article 是有结构的书面表达单位。它不是随意记录，而是有开头、展开和结尾的完整文本。

收纳 RU：essay、blog post、report、analysis、review

主体增益：它帮助主体区分”我有一些想法”和”我把想法组织成了一篇文章”。写文章的能力是结构化思考的外化。

常见用法：

常见搭配： - write an article 写一篇文章 - publish an article 发表文章 - the article is well-structured 文章结构良好

常用句型： - I need to turn these notes into an article. 我需要把这些笔记整理成一篇文章。 - A good article has a clear argument and supporting evidence. 好文章有清晰的论点和支撑证据。

概念安置卡：

RU 名称：Article

主位置：Language → Text → Article

关联位置：
- Language → Argument → Claim
- Work → Project → Project Artifact

关联动作：write, edit, publish, share

关联属性：structured, scattered, persuasive, informative

说明：Article 是结构化书面表达单位。它帮助主体将零散想法组织为有逻辑的完整文本。

15.7.2 Document 文档

Document 是承载信息、规则或流程的正式文本。它不是表达观点，而是记录和传递信息。

收纳 RU：manual、specification、contract、guide、reference

主体增益：它帮助主体区分”我知道怎么做”和”我把它写成了可复用的文档”。文档能力是将个人知识转化为可共享资产的关键。

常见用法：

常见搭配： - create a document 创建文档 - refer to the document 参考文档 - the document is outdated 文档已过时

常用句型： - I need to document this process. 我需要把这个流程写成文档。 - A good document reduces the need for repeated explanations. 好的文档减少了重复解释的必要。

概念安置卡：

RU 名称：Document

主位置：Language → Text → Document

关联位置：
- Work → Method → Framework
- Technology → System → Backend System

关联动作：create, update, reference, archive

关联属性：current, outdated, comprehensive, minimal

说明：Document 是信息记录单位。它帮助主体将个人知识转化为可共享、可复用的正式文本。

15.8 Concept 概念：Container 示例

15.8.1 Definition 定义

Definition 是对一个概念边界的精确描述。好的定义回答”它是什么”和”它不是什么”。

收纳 RU：formal definition、working definition、operational definition、boundary condition

主体增益：它帮助主体从”我大概知道这个概念”转向”我能精确说出它的边界”。没有清晰定义的概念无法被有效调用。

常见用法：

常见搭配： - define a concept 定义一个概念 - the definition is unclear 定义不清晰 - refine the definition 精炼定义

常用句型： - I need a clearer definition of this concept. 我需要这个概念更清晰的定义。 - A good definition tells you what something is and what it is not. 好的定义告诉你它是什么，以及它不是什么。

概念安置卡：

RU 名称：Definition

主位置：Language → Concept → Definition

关联位置：
- Language → Word & Phrase → Term
- Mind → Cognition → Mental Model

关联动作：define, refine, challenge, apply

关联属性：precise, vague, formal, operational

说明：Definition 是概念边界单位。它帮助主体精确描述一个概念的范围和限制。

15.8.2 Core Concept 核心概念

Core Concept 是一个域中最基础、最具解释力的概念。掌握核心概念是进入一个域的最快路径。

收纳 RU：first principle、key idea、foundational concept、central thesis

主体增益：它帮助主体识别”这个域里最重要的概念是什么”。不识别核心概念的人会在边缘概念上浪费精力。

常见用法：

常见搭配： - identify the core concept 识别核心概念 - grasp the core concept 掌握核心概念 - the core concept is misunderstood 核心概念被误解

常用句型： - The core concept of this field is feedback loops. 这个领域的核心概念是反馈循环。 - Once you grasp the core concept, the rest becomes easier. 一旦掌握核心概念，其余部分就变得容易。

概念安置卡：

RU 名称：Core Concept

主位置：Language → Concept → Core Concept

关联位置：
- Mind → Cognition → Mental Model
- Work → Method → Framework

关联动作：identify, grasp, explain, apply

关联属性：foundational, derivative, clear, contested

说明：Core Concept 是域内基础概念单位。它帮助主体识别并掌握一个领域最具解释力的核心思想。

15.9 Narrative 叙事：Container 示例

15.9.1 Personal Narrative 个人叙事

Personal Narrative 是主体讲述自己经历和身份的方式。它不是事实记录，而是主体如何组织和解释自己的故事。

收纳 RU：life story、turning point、identity narrative、origin story

主体增益：它帮助主体意识到”我如何讲述自己的故事”影响我的行动和选择。一个”我是受害者”的叙事会限制行动，而”我是学习者”的叙事会打开可能性。

常见用法：

常见搭配： - shape the personal narrative 塑造个人叙事 - the narrative is empowering 叙事赋予力量 - rewrite the narrative 重写叙事

常用句型： - My personal narrative shapes how I interpret events. 我的个人叙事塑造了我如何解释事件。 - I can choose to tell a different story about myself. 我可以选择讲述一个不同的自己的故事。

概念安置卡：

RU 名称：Personal Narrative

主位置：Language → Narrative → Personal Narrative

关联位置：
- Mind → Self → Self-narrative
- Relationship → Connection → Bond

关联动作：shape, tell, rewrite, share

关联属性：limiting, empowering, fixed, evolving

说明：Personal Narrative 是自我故事单位。它帮助主体识别并选择如何讲述自己的经历和身份。

15.9.2 Frame 框架叙事

Frame 是组织信息的叙事结构。它决定哪些信息被突出、哪些被忽略、哪些被连接。

收纳 RU：story arc、narrative frame、plot、theme

主体增益：它帮助主体理解”同一个事件可以用不同框架讲述”。意识到框架的存在，主体就能选择更有力的叙事方式。

常见用法：

常见搭配： - set the frame 设定框架 - shift the frame 切换框架 - the frame is misleading 框架有误导性

常用句型： - The frame of this story determines how the audience feels. 这个故事的框架决定了观众的感受。 - I need to shift the frame from “problem” to “opportunity”. 我需要把框架从”问题”切换到”机会”。

概念安置卡：

RU 名称：Frame

主位置：Language → Narrative → Frame

关联位置：
- Mind → Perception → Framing
- Language → Argument → Claim

关联动作：set, shift, challenge, reinforce

关联属性：positive, negative, narrow, expansive

说明：Frame 是叙事结构单位。它帮助主体理解并选择如何组织信息以产生特定效果。
