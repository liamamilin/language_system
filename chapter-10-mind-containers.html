12  第 10 章：Mind 的 Container 示例（Mind Containers）

12.1 本章要解决的问题

第 9 章梳理了 Mind 心智单位下的 8 个 Group：Perception、Attention、Memory、Emotion、Desire & Motivation、Cognition、Learning、Self。本章继续向下一层推进，展示每个 Group 下可以放置哪些 Container。

心智概念比身体概念更抽象，但安置逻辑一致。一个人说”我脑子很乱”——这句话太模糊。通过 Mind 树，他可以进一步安置为：注意力被频繁切割、工作记忆过载、情绪反应被触发、认知负荷太高、或者学习策略不匹配。概念越有位置，判断就越清楚。

12.2 Perception 感知：Container 示例

Perception 是信息进入心智的第一道门。它不同于 Sensation（Body → Sensation）——Sensation 是感觉器官接收信号，Perception 是大脑对信号的组织和解释。

12.2.1 Framing 框架

Framing 是解释信息的参考系。同一个数据在不同框架下有不同含义。

收纳 RU：perspective、context、reframing、narrative frame

主体增益：它帮助主体识别”我看到的不是事实，是一个框架下的解释”。意识到自己在用某个框架，是切换框架的第一步。

常见用法：

常见搭配： - shift the framing 切换框架 - narrow framing 狭窄的框架 - reframe the problem 重新定义问题

常用句型： - The framing of this problem limits what solutions we consider. 这个问题的框架限制了我们能考虑的解决方案。 - I need to reframe this situation. 我需要重新框定这个情况。

概念安置卡：

RU 名称：Framing

主位置：Mind → Perception → Framing

关联位置：
- Language → Narrative → Frame
- Mind → Cognition → Mental Model

关联动作：set, shift, challenge, broaden

关联属性：positive, negative, narrow, expansive

说明：Framing 是信息解释框架单位。它帮助主体意识到自己在用什么参考系解读信息。

12.3 Attention 注意：Container 示例

Attention 是认知资源分配机制。它是这个时代最稀缺的个人资源——不是因为注意力总量减少了，而是争夺注意力的外力指数级增加了。

12.3.1 Focus 专注

Focus 是注意力持续集中于一个目标的状态。它是深度工作的基础。

收纳 RU：deep work、flow、concentration、attention span

主体增益：它帮助主体判断”我在专注还是假装在专注”。很多时候，一个人坐在桌前几小时，但注意力已经被切割成碎片。没有 Focus 这个 Container，他只会归因为”效率低”。

常见用法：

常见搭配： - maintain focus 保持专注 - lose focus 失去专注 - deep focus 深度专注 - focus is fragmented 专注被切割

常用句型： - My focus has been fragmented this morning. 今天上午我的专注一直被切割。 - I need a block of uninterrupted time to get into deep focus. 我需要一段不被打断的时间来进入深度专注。

概念安置卡：

RU 名称：Focus

主位置：Mind → Attention → Focus

关联位置：
- Body → Energy → Mental Energy
- Technology → Tool → Cognitive Tool

关联动作：enter, maintain, lose, regain

关联属性：deep, shallow, sustained, fragmented

说明：Focus 是注意力集中状态单位。它帮助主体判断专注质量，而非只计算坐在桌前的时间。

12.3.2 Distraction 分心

Distraction 是所有将注意力从焦点偏移的因素。它分为内部因素（思绪漂移）和外部因素（通知、中断）。

收纳 RU：notification、interruption、mind wandering、multitasking

主体增益：它帮助主体区分”我不够自律”和”环境设计太差”。分心很大程度是环境问题，不是个人问题。识别分心来源是管理分心的第一步。

常见用法：

常见搭配： - reduce distraction 减少分心 - eliminate distractions 消除分心源 - internal distraction 内在分心 - external distraction 外部干扰

常用句型： - Notifications are a major source of distraction. 通知是分心的主要来源。 - I need to reduce external distractions during focused work. 在专注工作时，我需要减少外部干扰。

概念安置卡：

RU 名称：Distraction

主位置：Mind → Attention → Distraction

关联位置：
- Technology → Tool → Notification
- Mind → Attention → Focus

关联动作：remove, resist, reduce, manage

关联属性：internal, external, voluntary, involuntary

说明：Distraction 是注意力偏移因素单位。它帮助主体识别分心来源，将问题从意志力转移到环境设计。

12.4 Memory 记忆：Container 示例

Memory 是信息的存储和检索系统。它不是”记性好不好”的问题——它是身份和学习的基础。

12.4.1 Working Memory 工作记忆

Working Memory 是当前能操作的信息空间。它的容量有限，通常在 4-7 个组块之间。

收纳 RU：chunk、mental load、cognitive capacity

主体增益：它帮助主体理解”为什么有时处理不了复杂信息”——不是能力问题，是工作记忆空间已被占满。识别这一点后，主体会选择降低信息输入或使用外部工具来扩展工作记忆。

常见用法：

常见搭配： - working memory is overloaded 工作记忆过载 - working memory capacity 工作记忆容量 - offload working memory 卸载工作记忆负担

常用句型： - My working memory is overloaded right now. 我当前的工作记忆过载了。 - I need to write things down to offload my working memory. 我需要写下来以减轻工作记忆负担。

概念安置卡：

RU 名称：Working Memory

主位置：Mind → Memory → Working Memory

关联位置：
- Mind → Cognition → Cognitive Load
- Technology → Tool → Cognitive Tool

关联动作：load, unload, expand, overflow

关联属性：available, overloaded, fresh, depleted

说明：Working Memory 是认知桌面空间单位。它帮助主体判断何时需要降低信息输入或使用外部工具。

12.5 Emotion 情绪：Container 示例

Emotion 是对内外事件的自动反应系统。它不是”需要消除的东西”，而是携带信息的重要信号。

12.5.1 Negative Emotion 负向情绪

Negative Emotion 包括焦虑、恐惧、愤怒、悲伤、羞耻等。每种情绪都有不同的触发和功能。

收纳 RU：anxiety、fear、anger、sadness、shame、guilt

主体增益：它帮助主体识别具体情绪类型，而不是笼统地说”我心情不好”。不同的情绪需要不同的处理方法——焦虑需要降低不确定性，愤怒需要确认边界被侵犯，悲伤需要允许哀悼。

常见用法：

常见搭配： - feel anxiety 感到焦虑 - manage anger 管理愤怒 - trigger sadness 触发悲伤 - negative emotion arises 负向情绪出现

常用句型： - I am feeling anxiety about this decision. 我对这个决定感到焦虑。 - This anger may be a signal that my boundary was crossed. 这种愤怒可能是一个信号——我的边界被侵犯了。

概念安置卡：

RU 名称：Negative Emotion

主位置：Mind → Emotion → Negative Emotion

关联位置：
- Body → Stress → Stress Response
- Body → Sensation → Body Signal

关联动作：feel, identify, regulate, express

关联属性：mild, moderate, intense, overwhelming

说明：Negative Emotion 是负向情绪识别单位。它帮助主体精确识别情绪类型，而非笼统地归为"心情不好"。

12.5.2 Emotional Regulation 情绪调节

Emotional Regulation 是管理和回应情绪的策略集合。它不是压制情绪，而是让主体有选择地回应。

收纳 RU：cognitive reappraisal、acceptance、suppression、grounding

主体增益：它帮助主体区分”我被情绪控制”和”我在管理情绪”。有调节策略意味着主体有选择——情绪出现后，可以选择回应方式，而不是被自动反应控制。

常见用法：

常见搭配： - practice emotional regulation 练习情绪调节 - regulate emotions 调节情绪 - emotional regulation strategy 情绪调节策略

常用句型： - I need to regulate my emotion before responding. 在回应之前，我需要先调节一下自己的情绪。 - Emotional regulation is not about suppressing feelings. 情绪调节不是压制感受。

概念安置卡：

RU 名称：Emotional Regulation

主位置：Mind → Emotion → Emotional Regulation

关联位置：
- Mind → Self → Self-awareness
- Body → Stress → Stress Response

关联动作：apply, practice, automate, refine

关联属性：adaptive, maladaptive, conscious, automatic

说明：Emotional Regulation 是情绪管理策略单位。它帮助主体从被情绪控制转向有选择地回应。

12.7 小结

Mind 的 Container 比 Body 更抽象，但安置逻辑完全一致：先确定 Theme，再到 Group，再到 Container。每个 Container 都服务主体增益，并通过常见用法进入语言调用层。接下来进入 Part 4：Language。
