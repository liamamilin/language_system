6  第 4 章：个人生活 RU 树总览（RU Tree Overview）

6.1 本章要解决的问题

你已经有了筛选标准（主体增益原则）、识别工具（RU 五标准）和安置框架（四层结构）。现在你需要一张全景地图——八大 Theme 分别是什么？它们之间如何连接？你该从哪里开始？

本章提供个人生活 RU 树的全景。它不是百科目录，不是对每个 Theme 的详细介绍（那是 Part 2–9 的工作）。它是一张让你知道这个系统有多大的导航图。

6.2 八大 Theme 全景

个人生活 RU 树

Body（身体单位）        → 身体是一切能力的底盘
Mind（心智单位）        → 理解、学习、判断、情绪、自我的核心
Language（语言单位）     → 命名、表达、提问、思考的语言接口
Work（做事单位）        → 目标、任务、方法、项目、练习的做事系统
Relationship（人际关系） → 连接、信任、边界、合作、冲突的关系结构
Society（社会单位）     → 角色、组织、市场、规则的宏观结构
Technology（技术单位）   → 工具、软件、AI、系统的能力扩展器
Value（价值判断单位）   → 重要性、收益、成本、风险的判断系统

八个 Theme 不是平行分类，它们之间有结构性关系：

         Body（底盘）
            │
         Mind（处理器）
         ╱   │   ╲
Language  Work  Relationship
   │       │       │
   └─── Society ───┘
         │
   Technology（扩展器）
         │
      Value（调节器）

这是一个运行模型，不是分类学：

  • Body 是底层能源系统。 Mind 的建筑材料来自 Body 提供的能量和状态。疲劳的 Mind 无法专注，饥饿的 Mind 无法判断。
  • Mind 是核心处理器。 Language、Work、Relationship 是 Mind 的三个主要输出方向——你通过语言表达思考，通过做事执行思考，通过关系连接思考。
  • Language 是沟通接口。 它既与 Mind 紧密连接（思考离不开语言），也是你与外部世界（Society、Technology）的交互工具。
  • Work 是执行通道。 你把心智转化为产出，从目标到结果。
  • Relationship 是社会连接。 你通过 Mind 和 Language 建立关系，通过 Work 在关系中协作。
  • Society 是宏观环境。 Language、Work、Relationship 都在 Society 的规则和结构中运行。
  • Technology 是能力扩展器。 它横跨所有 Theme——你用技术扩展 Body（健康设备）、Mind（认知工具）、Language（AI 写作）、Work（自动化）、Relationship（社交平台）、Society（数字职业）、Value（决策工具）。
  • Value 是全局调节器。 它不独立于其他 Theme，而是作用于所有 Theme——你在每个域中都需要判断重要性、收益、成本、风险和意义。

这个模型不是理论的产物，它来自对个人实际运行的观察。你的身体状态影响你的思考质量（Body → Mind）。你的思考质量决定你的做事效率（Mind → Work）。你的做事结果影响你的社会位置（Work → Society）。你在社会中的体验反馈到你的情绪和自我认知（Society → Mind）。整个过程被你的价值观调节（Value）。

它不是循环，是动态反馈系统。

6.3 快速速览

6.3.1 Body 身体单位

Body 是八大 Theme 中的基础层。它覆盖物理存在的一切方面：精力、睡眠、饮食、运动、健康、感官、压力、疲劳。

为什么 Body 是第一 Theme？因为所有其他 Theme 的运行都建立在身体状态之上。你无法在疲劳状态下做好思考（Mind），无法在压力高峰期做好表达（Language），无法在身体不适时高效做事（Work）。

Body 包含 8 个 Group： Energy（精力）、Sleep（睡眠）、Diet（饮食）、Movement（运动）、Health（健康）、Sensation（感官）、Stress（压力）、Fatigue & Pain（疲劳与疼痛）

6.3.2 Mind 心智单位

Mind 覆盖心理和认知的一切方面：你如何感知世界、如何分配注意力、如何记忆、如何感受、你被什么驱动、你如何思考、如何学习、你是谁。

Mind 可能是最复杂的 Theme，因为它是一切”个人处理”的发生地。

Mind 包含 8 个 Group： Perception（感知）、Attention（注意）、Memory（记忆）、Emotion（情绪）、Desire & Motivation（欲望与动机）、Cognition（认知）、Learning（学习）、Self（自我）

6.3.3 Language 语言单位

Language 是你的概念接口。你通过它命名世界、表达思考、提出问题和传递指令。在大模型时代，语言能力越来越等同于概念安置能力。

Language 包含 8 个 Group： Word & Phrase（词与短语）、Sentence（句子）、Text（文本）、Concept（概念）、Question（问题）、Argument（论证）、Narrative（叙事）、Instruction（指令）

6.3.4 Work 做事单位

Work 覆盖你如何做事、完成事和从做事中学习。它包含从目标设定到反馈改进的完整做事链条。

Work 包含 8 个 Group： Goal（目标）、Plan（计划）、Task（任务）、Method（方法）、Project（项目）、Practice（练习）、Problem（问题）、Feedback（反馈）

6.3.5 Relationship 人际关系单位

Relationship 覆盖人与人的连接结构。它关注的不是”和谁关系好”，而是建立、维持和解决人际关系所需的概念系统。

Relationship 包含 8 个 Group： Connection（连接）、Trust（信任）、Boundary（边界）、Intimacy（亲密）、Cooperation（合作）、Conflict（冲突）、Influence（影响）、Relational Role（关系角色）

6.3.6 Society 社会单位

Society 覆盖个人在宏观社会中的位置。你作为一个体如何在组织的等级、市场的规则和职业的路径中定位自己。

Society 包含 8 个 Group： Role（角色）、Group（群体）、Organization（组织）、Institution（制度）、Market（市场）、Rule（规则）、Career（职业）、Platform Ecology（平台生态）

6.3.7 Technology 技术单位

Technology 覆盖所有扩展个人能力的技术工具——从一把锤子到大语言模型。

Technology 包含 8 个 Group： Tool（工具）、Software（软件）、AI Model（AI 模型）、Data（数据）、System（系统）、Technology Platform（技术平台）、Automation（自动化）、Workflow（工作流）

6.3.8 Value 价值判断单位

Value 覆盖你如何判断什么重要、什么值得、什么划算、什么对、什么有意义。

Value 包含 8 个 Group： Importance（重要性）、Benefit（收益）、Cost（成本）、Risk（风险）、Purpose（目的）、Standard（标准）、Ethics（伦理）、Meaning（意义）

6.4 八域之间的主位置与关联位置

同一 RU 在不同 Theme 有不同角色。下表展示跨域 RU 的主位置和关联位置：

RU 主位置 关联位置
focus Mind → Attention → Focus Body → Energy → Mental Energy
prompt Language → Instruction → Prompt Technology → AI Model → Model Input
feedback Work → Feedback Language → Argument / Relationship → Connection
risk Value → Risk Work → Decision / Society → Career
stress Body → Stress Mind → Emotion → Negative Emotion
attention Mind → Attention Work → Task → Focus / Learning
career Society → Career Work → Goal / Value → Meaning
workflow Technology → Workflow Work → Method / System

关联位置的作用是连接。当你在 Work 中讨论 feedback 时，你可以通过关联位置看到它也属于 Language 和 Relationship——这提醒你反馈不仅是工作流程的一部分，也是语言能力和关系质量的体现。

6.5 如何避免把本书读成百科分类

这是最容易被误解的一章。你看到八个 Theme、六十四个 Group、一百多个 Container——很容易觉得这是一个静态分类系统，像元素周期表或图书馆分类法。

这不是分类系统，是运行架构。

几个区别：

分类系统回答”这个东西是什么”。运行架构回答”我如何使用这个东西来提升能力”。

读书虫分类把蝴蝶属于鳞翅目。运行架构把”注意力”放在 Mind 下的 Attention，因为你需要知道如何管理注意力来提升做事效率。

分类系统追求穷尽。运行架构追求够用。

八大 Theme 不是所有可能域，是你个人生活中最重要的八个域。如果你的生活中某个域占了很大比重（比如你没有工作但必须在某个比赛中提升技能），那就不要死守八大 Theme，把你的训练作为 Work 的核心域。

分类系统的结构是静态的。运行架构的结构是动态可调的。

Container 可以增加，Leaf 可以频繁变更，关联位置可以根据你当前的主项目调整。

读完本章，你应该已经对全树有了一个基本印象。如果你感觉信息量太大，没关系。接下来的 Part 2–9 会深入每个 Theme 和 Group，你不需要一次性记住所有内容。

6.6 语言调用意识：全书的隐藏主线

本书的主线看起来是”概念安置”——把 RU 放到 Theme → Group → Container 中。但隐藏的主线是”语言调用”。每一个被你安置到树上的 RU，最终应该能被你说出来、写出来、用出来。

这就是为什么从第 7 章开始，每个 Container 都会包含常见搭配和例句。当你在学习这些 Container 时，不要只记位置，试着把那些例句读出来——那是你的语言调用训练。

建议的下一步：打开附录 A，看一眼 RU 树总表。不需要通读，只需要记住八个 Theme 的名字和它们的大致位置。然后挑一个你最关心或最困惑的 Theme 开始读。

如果你不确定从哪个 Theme 开始，从 Body 开始。身体是一切的基础。
