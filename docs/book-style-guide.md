# Book Style Guide

This file records style decisions for the current 15-chapter version. It is not part of the rendered book.

## Core Rule

The book teaches concept placement, not knowledge accumulation. Every explanation should help the reader locate, distinguish, connect, or call a concept.

## Language Policy

- Main text is English.
- Chinese parentheses are used for difficult terms, compressed ideas, or useful anchors.
- Do not make every sentence bilingual.
- Use Chinese only when it lowers decoding friction（降低理解阻力）.

## Fixed Terms

Use these forms consistently:

- RU
- RU Tree
- Referable Unit
- Subject Gain Principle
- Theme
- Group
- Container
- Leaf
- Primary Position
- Associated Position
- Domain Language
- Theme Toolbox
- Common misplacement
- Common misreading
- Use sentence

Lowercase is acceptable inside ordinary sentences when the term is not being used as a formal label, but headings, tables, cards, and templates should use the fixed forms above.

## Theme Rule

The eight Themes are fixed:

- Body
- Mind
- Language
- Work
- Relationship
- Society
- Technology
- Value

Do not write Time, Ethics, Market, or Workflow as if they were top-level Themes. Use their proper positions, such as Value → Ethics or Technology → Workflow.

## Chapter Pattern

Theme Toolbox chapters should normally include:

1. Opening Problem
2. Boundary when needed
3. Domain Language
4. Group Map
5. Core Containers
6. Misplacement Patterns
7. Causal Chain
8. Placement Practice
9. Chapter Output

Container entries should include the concept definition, Common misplacement or Common misreading, and at least one Use sentence.

## Tone

The tone should be clear, practical, and conceptual without becoming academic. Prefer sentences that help the reader say or do something.

Weak:

> This concept is important.

Better:

> This concept helps separate market price from human value.
