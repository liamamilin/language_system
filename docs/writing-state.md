## Planned Restructure

新版目标结构：

- Part 1: Method and Map（4 章）
- Part 2: Body / Mind（Body Toolbox, Mind Toolbox）
- Part 3: Language / Work（Language Toolbox, Work Toolbox）
- Part 4: Relationship / Society（Relationship Toolbox, Society Toolbox）
- Part 5: Technology / Value（Technology Toolbox, Value Toolbox）
- Part 6: Use and Training（How to Place, Diagnose, Maintain）

重构原则：

- 八个 Theme 保持独立，不合并为双域章节。
- 原先每个 Theme 的 overview / groups / containers 三章压缩为一个 Theme Toolbox。
- Group 作为工具箱内部地图保留，不再单独成章。
- Container 成为章节主体，但必须服务领域语言、常见错位、因果链和调用句，不写成知识罗列。
- 正文使用英文，难词或压缩句用中文括号辅助理解。
- 先选一个 Theme 试改，确认模板成立后再迁移其余 Theme。
