33  附录 C：每日训练法（Daily Training）

33.1 训练总目标

让 RU 树从”读过的概念”变成”可调用的能力”。阅读本书只是在看地图，训练才是真正走一遍。

33.2 三个阶段

33.2.1 第一阶段：只练 Theme（第 1-2 周）

每天花 10 分钟做一件事：给一个日常概念找到 Theme。

你在一天中遇到一个概念——可能是”sunk cost”“focus”“teamwork”“deadline”“sleep quality”。不要想太多，只回答：这属于八大 Theme 中的哪一个？

Day 1-3：每天 3 个概念 Day 4-7：每天 5 个概念 第二周：每天 5 个概念 + 确认 Theme 归属

训练目标：八个 Theme 名称变成你的自动分类架。

33.2.2 第二阶段：练 Theme → Group（第 3-4 周）

每天 5 个 RU，每个 RU 完成：

  1. 确定 Theme
  2. 确定 Group

示例：“sleep debt” → Body → Sleep “cognitive load” → Mind → Cognition “opportunity cost” → Value → Cost

训练目标：64 个 Group 在你脑中是导航目录，不是纸上的表格。

33.2.3 第三阶段：练 Theme → Group → Container（第 5-8 周）

每天 5 个 RU，完成完整的三层安置：

RU → Theme → Group → Container

示例： “deep work” → Mind → Attention → Focus “backlog” → Work → Task → Task State “trust repair” → Relationship → Trust → Trust Repair

这个阶段最难，也最关键。Container 是你最终要内化的层级。能快速给任何 RU 找到 Container——哪怕它是你第一次遇到的——你就真正有了 RU 树的调用能力。

33.3 每天 5 个 RU 安置

训练流程：

  1. 早上或晚上固定时间，打开一个笔记
  2. 回顾当天接触到的新概念或常用概念
  3. 选 5 个做安置
  4. 用概念安置卡格式记录

时间投入：每天 10-15 分钟。比刷社交媒体的时间少得多。

33.4 每周一次主树审查

每周花 15 分钟检查 RU 树：

  1. 新增：这周有没有新的 RU 需要进入主树？
  2. 调整：已有的 RU 位置对不对？需不需要调 Container？
  3. 移除：哪些 RU 其实没用过？移出到外部知识层。
  4. 合并：两个 RU 是不是同一个概念的不同名字？合并。
  5. 连接：发现了什么新的 RU 间连接？记录关联位置。

33.5 如何用大模型辅助训练

33.5.1 场景 1：检查安置

我学到一个概念叫 "X"。我觉得它应该放在 ___ → ___ → ___。
这个位置对吗？还有没有更好的位置？

33.5.2 场景 2：生成关联语言

RU "X" 的主位置是 ___ → ___ → ___。
请列出它的 3 个典型关联动作、3 个典型关联属性。

33.5.3 场景 3：跨域连接

RU "X" 的主位置是 ___ → ___ → ___。
它可能在哪些其他 Theme 中有关联位置？
分别是什么 Group 和 Container？

33.5.4 场景 4：考试

请随机给我一个 RU（日常高频概念），我来给它找位置。
我先给出我的安置，然后你来评估。

33.6 评估标准

每个训练阶段结束时，问自己：

  • 你能不看书列出八个 Theme 吗？
  • 你能不看书说出每个 Theme 下的三个 Group 吗？
  • 给你一个 RU，你能否在 5 秒内确定它的 Theme？
  • 给你一个 RU，你能否在 30 秒内确定它的 Container？

如果你卡住了，回到对应的阶段继续训练。这本书的训练系统是渐进的，跳过任何阶段都会导致后面不稳。
